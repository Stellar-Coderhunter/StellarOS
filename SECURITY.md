# Security Policy

## Reporting a Vulnerability

If you discover a security issue in StellarOS, please do not open a public issue with exploit details.

Until a dedicated private reporting channel is published, please report the issue privately to the project maintainers through the safest available private contact method for this repository.

When reporting a vulnerability, include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigation

## Scope

Security reports are especially helpful for:

- Bootstrap scripts that install packages or execute remote commands
- Key, wallet, or credential handling
- Deployment helpers
- Local testnet tooling

## Disclosure

We will aim to acknowledge reports quickly, investigate responsibly, and coordinate a fix before public disclosure when appropriate.
